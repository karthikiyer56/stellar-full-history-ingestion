## CANONICAL DESIGN TRUTHS

These are ground truth. Any doc that contradicts these must be fixed:

1. **BSB terminology**: The correct term is "BSB instance" (not "BSB batch"). The correct config key is `num_instances` (not `bsb_batches`). The correct concept label is "BSB parallelism" (not "BSB batches"). No document may use "BSB batch", "BSB batches", or "bsb_batches" anywhere (except in historical references that explicitly say "formerly called").

2. **BSB parallelism model**: All 20 BSB instances within a range run **concurrently** (in parallel). Each owns a 500K-ledger slice (50 chunks). This is explicitly a property of `[backfill.bsb]` only — `[backfill.captive_core]` has no BSB parallelism. "20 BSB instances" means 20 concurrent goroutines per range, not 20 sequential workers.

3. **Non-contiguous completion at crash time**: Because BSB instances run in parallel, completed chunks at crash time are NOT guaranteed to form a contiguous prefix. Gaps between completed chunks are expected and normal. The resume rule scans ALL 1,000 chunk flag pairs — not just up to the first incomplete one.

4. **Config structure**: `[backfill.bsb]` and `[backfill.captive_core]` are mutually exclusive subsections. Exactly one must be present. `[backfill]` is the top-level section. `[backfill.bsb]` contains `num_instances` (not `bsb_batches`). There is no `ledger_backend` toggle string at the top level.

5. **Meta store chunk flags**: Per-chunk flags are `lfs_done` and `txhash_done`. These exist BECAUSE of parallel BSB instances — the design tracks per-chunk completion (not per-BSB-instance completion) specifically to handle non-contiguous completion. The meta store design doc must articulate this rationale.

6. **Chunk skip rule**: A chunk is skippable only when BOTH `lfs_done="1"` AND `txhash_done="1"`. Future: extends to ALL three flags when `events_done` is added. A chunk with only `lfs_done="1"` is NOT skippable — only the LFS write is skipped, txhash is redone.

7. **getEvents placeholder**: Must appear in ALL of: 03, 04, 05, 06, 07, 08 (query routing), 02 (meta store), and FAQ. The placeholder section heading must be `## getEvents Immutable Store — Placeholder` (exact).

8. **No `global:mode` key** in meta store. No `transitioning/` directory on disk. Mode from `--mode` flag only.

9. **RecSplit async overlap**: When range N ingestion finishes, the orchestrator slot is freed and range N+1 starts ingesting immediately. RecSplit for range N runs concurrently with range N+1 ingestion. RecSplit does NOT block range N+1 from starting.

10. **Mermaid only, no ASCII art**: All diagrams must be mermaid. No ASCII boxes, no pipe-and-dash tables used as diagrams.
